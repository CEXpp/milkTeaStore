# 1 文档导读

<a id="_Toc100004"></a>

## 1.1 文档定位

本文档是文档链最后一环：SRS（做什么）→ HLD（为什么这样设计）→ LLD（敲什么）→ 本文（何时做、按什么顺序做、做到什么程度算完成）。内容两部分：排期规划（人力、里程碑、甘特图）与施工步骤（38 张原子任务卡，五件套齐备）。

<a id="_Toc100005"></a>

## 1.2 执行模式：真人主导 + AI 辅助

- 两名全栈开发（下称 A / B）为主执行者，按任务卡顺序施工；卡住时可将任务卡原文（连同 LLD 对应章节）投喂给 AI 助手生成参考代码，由真人评审合入。
- 因此任务卡同时照顾两种读者：人读「实现要点/完成标准」，AI 读「涉及文件/验证命令」——五件套（涉及文件/实现要点/测试用例/验证命令/完成标准）一项不少。
- 纪律：AI 生成的代码必须通过任务卡的验证命令才算完成；文档契约（表名/路径/签名）与 LLD 冲突时以 LLD 为准并登记。

<a id="_Toc100006"></a>

## 1.3 使用方式

- 开工前：第 2 章排期签核 → 附录 A 环境密钥逐项确认。
- 每日：按第 3 章索引的依赖顺序领卡施工 → 完成 → 勾完成标准 → git commit（消息含任务号，如 T12: mock payment + pickup code）。
- 每周：对照里程碑表自查进度；落后超过 2 人日动用周末机动或缓冲池，并更新本文档修订记录。

# 2 排期总览

## 2.1 人力模型与工作量

- 人力：2 名全栈，每日有效投入 4 小时/人（合计 8 小时/天 = 1 人日/天）；建议分工 A 偏后端、B 偏前端，交叉备份。
- 工作量：38 个原子任务合计 45 人日（逐卡估点见第 3 章索引），加 20% 风险缓冲约 9 人日，总计约 54 人日。
- 排期口径：按工作日推进（周末与国庆假期为机动缓冲池，落后可补）；开工 2026-09-14（周一），完成约 2026-12-04，历时约 11.5 周。

## 4.2 任务卡（五件套）

**  T01 · 工程骨架初始化（单仓三目录）**

工期：1 人日｜依赖：无｜建议分工：A

**涉及文件**

- 仓库根：README.md / .gitignore

- backend/src/main/java/com/milktea/order/{user,product,order,payment,statistics,ai,common}/package-info.java

- docker/（空目录占位）

**实现要点**

- git init 单仓库；三个顶层目录 backend / admin-web / miniapp + docker
- backend 用 Maven 手建（Spring Boot 3.3.x parent）：依赖 web / validation / lombok / mybatis-plus-spring-boot3-starter / flyway-core + flyway-mysql / mysql-connector-j / jjwt / spring-boot-starter-test
- 包结构按 LLD 2.1：com.milktea.order 六域 + common；每包先放 package-info.java 占位，说明职责（内容抄 HLD 3 章各域一句话）
- application.yml 先空壳（dev profile 名占位）

**测试用例**

- mvn compile 通过，包结构存在
- git 提交基线 commit

**验证命令**

```text
cd backend && mvn -q compile && echo BUILD_OK
git log --oneline | head -1
```

**完成标准**

- □ 单仓三目录 + docker 目录就位
- □ mvn compile 零报错
- □ 六域包结构完整且带职责说明

**  T02 · 基础设施容器（MySQL + MinIO）**

工期：0.5 人日｜依赖：T01｜建议分工：B

**涉及文件**

- docker/docker-compose.yml
- docker/.env（git 忽略，含数据库密码样例）
- backend/src/main/resources/application-dev.yml（datasource/minio 指向容器）

**实现要点**

- compose 内容照 LLD 10.1 全文：mysql:8（3306，数据卷，healthcheck）+ minio（9000/9001，数据卷）；本阶段先不含 backend 服务
- 虚拟机桥接网络；宿主机与 IDEA 通过虚拟机 IP 访问
- .env 写 MYSQL_ROOT_PASSWORD / MINIO_ROOT_USER / MINIO_ROOT_PASSWORD 样例值，真实值不进 git

**测试用例**

- 两容器均 healthy
- 宿主机能用 mysql 客户端连上 3306；浏览器打开 minio 控制台 9001 可登录

**验证命令**

```text
cd docker && docker compose up -d && docker compose ps
docker compose ps --format '{{.Name}} {{.Status}}' | grep healthy | wc -l  # 期望 2
```

**完成标准**

- □ compose 一键拉起双容器且 healthy
- □ application-dev.yml 连接参数可用
